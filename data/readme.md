## datasets

In this repository the metadata can be found for the datasets that have been used in the dissertation _Reliable and Relatable Journalists: A Digital Humanities Analysis of Ethos in Personal Journalism_

[Data set I]( contains the metadata of the dataset that has been used for chapter 4.
[Data set II] contains the metadata of the dataset that has been used for chapter 5 and 6. 
[Ethos utterances dataset]( contains all the metadata and relevant words from the ethos utterances of journalists that has been used for chapter 5 and 6. 

For chapter 5 a subset of ethos utterances has been selected in which there was a sensory verb present, i.e. to see, to look, to hear, to listen, to taste, to smell, to touch, or to feel. The data has subsequently been annotated on whether or not the ethos utterances were part of a confessional journalism article. The metadata and the annotations can be found in the [annotated witnessing dataset]. From all confessional articles, only confessional columns written by journalists have been analysed through qualitative textual analysis. The metadata on this dataset can be found in the [confessional column dataset].

For chapter 6, a dictionary of emotion words have been constructed. For this purpose, all adjectives, nouns, verbs that were syntactically related to journalistic first-person pronouns have been annoted following the appraisal theory. The annotations can be found here: [nouns], [verbs I], [verbs II] and [adjectives].
